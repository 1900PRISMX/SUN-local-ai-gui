# SUN-local-ai-gui
# S.U.N. — your own AI, on your own PC

A private local-AI interface for Ollama. A living reactor that reacts as the AI thinks, live CPU/GPU/temperature meters, memory that remembers you across sessions, and full color/size customization. Runs 100% on your machine — nothing leaves your computer. Works with any model.

## What you need (one time, all free)
1. **Python** — get it at python.org. On the first install screen, CHECK the box "Add Python to PATH".
2. **Ollama** — the free app that runs the AI. Get it at ollama.com.

## How to start it
1. Download `sun_setup.py` from this page (click it, then the download icon).
2. Put it anywhere — your Documents folder is fine.
3. Open a terminal (Windows: type `powershell` in the Start menu).
4. Run this line:
   - **Windows:** `py "$env:USERPROFILE\Documents\sun_setup.py"`
   - **Mac/Linux:** `python3 ~/Documents/sun_setup.py`
5. First run sets up and downloads a small AI model. Wait a few minutes — one time only.
6. Your browser opens with SUN. Start typing!

To open it again later, just run the same line.

## Make it yours
Click the gear (⚙) top-right. Change colors, reactor size, chat size — it remembers your choices.

## Good to know
- Runs on your computer only. No account, no tracking, nothing sent anywhere.
- Works with any Ollama model — pick it from the dropdown. No model yet? It offers to grab a small one.
- GPU meter needs an NVIDIA card; other cards show a dash there, everything else works.
- Your chats save in `sun_memory.db` next to the file. Delete it to wipe memory.
